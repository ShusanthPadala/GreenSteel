# GreenSteel: AI-Driven Environmental Monitoring System

## Overview

GreenSteel is an AI-driven environmental monitoring dashboard designed for integrated steel plants. The system enables real-time monitoring of emissions, ESG performance, environmental alerts, sustainability metrics, and plant operations.

This project was developed as part of an industrial full-stack development internship project.

---

## Features

### Authentication
- Login page
- Dashboard access control

### Dashboard
- Real-time KPI monitoring
- Environmental summary

### Alert Management

- Warning alerts

### Reports
